# Trading Lab

Python stock analysis, risk management, educational backtesting, budgeting and Groww integration.

Backtests are hypothetical and do not guarantee future returns.

## Setup
```bash
python -m venv .venv
.venv\\Scripts\\activate
pip install -r requirements.txt
copy .env.example .env
streamlit run app/main.py
```

Keep `LIVE_TRADING_ENABLED=false` while learning/testing.
